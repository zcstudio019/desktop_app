# 个人抵押类产品库

适用标签：个人抵押贷、个人房抵贷、消费抵押贷、房产抵押、住宅抵押、商铺抵押、一押、二押、上海房产、无企业房抵、产品匹配​
适用场景：
当客户为个人借款人，名下或家庭名下有可抵押房产，但不一定具备企业经营条件，或者资金用途偏个人消费、家庭周转、债务优化等合规用途时，可优先从本产品库中匹配方案。重点关注房产区域、房屋类型、房龄、面积、估值、抵押状态、产权人关系、客户年龄、个人征信、收入流水、负债情况和资金用途。​
适合客户画像：​
1. 个人或家庭名下有住宅、商铺等可抵押资产；​
2. 没有企业或企业条件不适合经营贷；​
3. 需要比信用贷更高的额度或更长期限；​
4. 征信整体正常，有稳定还款来源；​
5. 能配合房产评估、抵押登记、面签等流程。​
不适合优先匹配：​
6. 房产存在查封、产权纠纷、严重瑕疵；​
7. 房屋区域、房龄、性质不符合银行准入；​
8. 产权人不配合或产权关系复杂；​
9. 客户收入无法覆盖月供；​
10. 资金用途不合规或无法说明合理用途。
