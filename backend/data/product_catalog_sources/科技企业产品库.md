# 科技企业产品库

适用标签：科技企业、高新技术企业、专精特新、科技型中小企业、小巨人、知识产权贷、人才贷、科创贷、研发企业、轻资产企业、产品匹配​
适用场景：
当客户属于科技型企业、高新技术企业、专精特新企业、科技型中小企业、小巨人企业，或者企业具有知识产权、研发投入、科创园区、股权融资、优秀人才背景等特征时，可优先从本产品库中匹配方案。重点关注企业科技资质、知识产权、研发投入、纳税开票、法人或股东学历背景、园区属性、融资记录、成立时间、征信情况和资产负债率。​
适合客户画像：​
1. 高新技术企业、专精特新企业、科技型中小企业、小巨人企业；​
2. 有软件著作权、专利、商标、知识产权等科技资产；​
3. 纳税或流水不一定很高，但具备科技资质或成长性；​
4. 企业位于科创园区、张江、漕河泾等科技园区；​
5. 法人、实控人或核心股东具备较好学历、人才或研发背景。​
不适合优先匹配：​
6. 没有真实科技属性，仅包装为科技公司；​
7. 科技资质过期或无法提供证明；​
8. 征信严重异常、涉诉被执行、经营异常；​
9. 财务指标明显恶化且无法解释；​
10. 行业不符合科技贷或政策性产品支持方向。

- 原章节：第 5 章  消费金融公司
- 原分组：▶ 消费贷

| 字段 | 内容 |
|---|---|
| 贷款类型 | 信用贷（企业，科技型企业专项，线上标准化） |
| 担保方式 | 企业信用+法人夫妻双方个人连带责任保证担保 |
| 利率 | 年化利率：4%左右；备注：根据企业科技资质及经营情况定 |
| 最高额度 | 1000万 |
| 还款方式 | 先息后本，提前还款无违约金 |
| 贷款授信最长期限 | 12期（按月，约1年） |
| 是否随借随还 | 否（先息后本，12期） |
| 收款账户 | 对公账户 |
| 准入条件 | 法人变更：法人变更>6个月，持股≥30%；注册时间：用款企业在当地注册满一年，当地有固定经营场所 |
| 申请人要求 | 年龄：22-65周岁；企业成立时间：2年以上，变更要求满一年 |
| 科技资质要求（满足其一，且为小型或微型企业） | 专精特新企业：国家级/省级/市级'单项冠军/隐形冠军'企业、专精特新'小巨人'企业、'科技小巨人'企业、专精特新培育企业等；高新技术企业：国家/省/市高新技术企业、高新技术企业培育入库企业等；科技型中小企业：当年或上一年度在'科技型中小企业服务'网站公告，取得入库编号，资质未被撤销 |
| 纳税要求 | 正常纳税，纳税等级A/B，无严重税务处罚 |
| 合规要求 | 无其他不良信息，无涉诉金融案件，无限高被执行等 |
| 征信要求 | 逾期：无当前逾期；近1年内逾期或欠息30天（含）以内累计≤6次；无逾期或欠息90天（不含）以上信用记录；对外担保：对外担保信息中风险分类等级为正常；负债规模：负债笔数无要求；建议整体负债规模不超年营收25%（优质企业放宽）；担保方式：法人夫妻双方个人连带责任保证担保 |
| 办理流程 | ①资料预审 → ②扫码过系统 → ③补充资料+开对公账户 → ④终审通过放款 |
| 经验总结 | 鑫e科企是南京银行专为科技企业（专精特新/高新/科技型中小企业）推出的线上标准化信用贷，最高1000万，年化4%左右，12期先息后本；核心门槛：企业满2年/法人持股≥30%/变更>6月/注册满1年/有固定经营场所；必须满足三类科技资质之一（专精特新/高新/科技型中小企业）且为小微企业；纳税A/B级；负债笔数无要求但建议不超年营收25%；法人夫妻双方连带担保 |
| 特殊优势及备注 | 线上标准化，扫码两步授权即可完成审批；无负债笔数要求（优质企业负债可放宽）；提前还款无违约金；对公账户放款；准入条件清晰（满足一类科技资质+纳税A/B级）；法人夫妻双方须连带担保（需配偶配合）；需在当地有固定经营场所；法人变更须>6个月且持股≥30% |
| 适合客户 | 满足专精特新/高新技术企业/科技型中小企业资质之一、企业满2年（法人变更>6月/持股≥30%/注册满1年）、纳税A/B级、无当前逾期（近1年逾期≤6次且无90天以上记录）的小微科技企业法人，最高1000万，年化4%左右，线上审批快，提前还款无违约金，法人夫妻双方需连带担保 |
