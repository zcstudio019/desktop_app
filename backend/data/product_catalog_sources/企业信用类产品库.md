# 企业信用类产品库

适用标签：企业信用贷、企业经营贷、税贷、流水贷、开票贷、收款码贷、小微企业、个体工商户、无抵押贷款、经营周转、产品匹配​
适用场景：
当客户有正常经营企业或个体工商户，但没有可抵押房产，或者暂时不想做房产抵押时，可优先从本产品库中匹配方案。重点关注客户的企业成立时间、法人或实控人征信、企业征信、纳税记录、开票金额、对公流水、个人经营流水、收款码流水、负债情况、查询次数、行业属性和经营稳定性。​
适合客户画像：​
1. 有营业执照、实际经营的小微企业主或个体工商户；​
2. 有纳税、开票、流水、收款码等经营数据；​
3. 希望申请无抵押、纯信用类经营贷款；​
4. 有短期周转、采购备货、支付货款、经营扩张需求；​
5. 企业或法人征信整体正常，当前无严重逾期或重大负面记录。​
不适合优先匹配：​
6. 没有真实经营或营业执照长期空壳；​
7. 征信当前逾期、涉诉被执行、负债明显过高；​
8. 企业经营流水、纳税、开票长期异常；​
9. 属于金融、房地产、博彩、违法违规等禁入或高风险行业。
