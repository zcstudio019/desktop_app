# 企业抵押类产品库

适用标签：企业抵押贷、房抵经营贷、经营性抵押贷、企业主房抵贷、上海房产、住宅抵押、商铺抵押、厂房抵押、一押、二押、经营周转、产品匹配​
适用场景：
当客户是企业主、个体工商户、法人、股东或实际控制人，并且本人、配偶、直系亲属或公司名下有可抵押房产时，可优先从本产品库中匹配方案。重点关注房产所在区域、房屋类型、房龄、面积、估值、抵押状态、一押/二押情况、产权人关系、企业成立时间、经营流水、征信情况和贷款用途。​
适合客户画像：​
1. 有上海或指定区域可抵押房产；​
2. 有企业、个体工商户或真实经营背景；​
3. 需要较高额度、较低利率或较长期限；​
4. 可接受房产抵押、评估、下户、抵押登记等流程；​
5. 资金用途与经营周转、采购、备货、续贷等相关。​
不适合优先匹配：​
6. 房产产权不清晰、存在重大纠纷或查封；​
7. 房龄、区域、房屋性质不符合银行准入；​
8. 非直系亲属房产且产品不接受；​
9. 客户无法提供真实经营用途；​
10. 征信严重异常、当前逾期或涉诉执行风险较高。
